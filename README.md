## TAWTHIQ — open proofs (English, short)

Each experiment folder holds an open proof (`اثبات.md`), byte-identical copies of the raw run outputs (`دليل/`), a `MANIFEST.sha256`, a QR code that opens the proof, and the proof's own hash to print beside the QR. The root holds the very bundle that was measured (`حزمة-2195/`: a 2195-ring hash ledger, 80 signed chain seals, 2192 ring signatures, 3 public keys, 47 OpenTimestamps proofs, and the stdlib-only verifier) plus a root manifest. A judge scans, compares the hash, clones, runs `shasum -a 256 -c MANIFEST.sha256`, runs the verifier on the bundle and gets byte-identical output, then replays the attacks and picks any ring to tamper with. Needs only Python 3 and `ssh-keygen`; no network after download; no access to our private code. What is never published: vault contents, source filenames, private keys, our methodology and banks.
