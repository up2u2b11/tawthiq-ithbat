## 3 · طريقُ الاستدلالِ خطوةً خطوة — بلا شبكةٍ بعدَ التنزيل

**تحتاج:** Python 3 و`ssh-keygen`.

1. قارنْ بصمةَ هذا الملفِّ بالمطبوعةِ بجوارِ الرمز: `shasum -a 256 اثبات.md`.
2. `git clone --depth 1 https://github.com/up2u2b11/tawthiq-ithbat.git && cd tawthiq-ithbat` · سجّلْ `git log -1 --format=%H`.
3. في الجذر `shasum -a 256 -c MANIFEST.sha256`، ثمّ `cd تجربة-عبث-01_9-أكتوبر-2026 && shasum -a 256 -c MANIFEST.sha256` — كلُّ سطرٍ `OK`.
4. اقرأِ الخام: `دليل/out_a2_forge__v_trunk.txt` (يقولُ «✅ سليم») مقابلَ `دليل/out_a2_forge__v_fixed.txt`؛ و`دليل/natija.txt` لرموزِ الخروج. الورقةُ الكاملةُ `دليل/qiyas.md`.
5. **أعِدِ الهجومَ الثانيَ بنفسِك على الحزمةِ المرفقة** — متحقّقُ الجذعِ يومَها هو نفسُه `v_qadim.py` في الإثباتِ 02 (بصمتُه `3efc0730…`)، والمصلَحُ `v_main.py` (يحملُ إصلاحَ `97b6d3bc` نفسَه):
   ```

   ```
   (الأعدادُ اليومَ 2195 حلقةً و80 ختمًا لا 2165 و75؛ السلوكُ هو هو.)
