## 1 · الدعوى

1. تغييرُ **حرفٍ واحد** في أيِّ حلقةٍ موقَّعةٍ من دفترِ السلسلةِ يُظهِرُ سطرًا جديدًا في المتحقّقِ المستقلّ `tahaqquq_mustaqill.py` (مكتبةُ Python المعياريّةُ + `ssh-keygen`).
2. تزويرُ حلقةٍ **مع إعادةِ حسابِ كلِّ الأختامِ بعدَها** حتى يتّصلَ الربطُ يُمسَكُ بالتواقيعِ لا بالربط.
3. المتحقّقُ القديمُ (ما قبلَ 4 نوفمبر 2026) كان يمرّرُ الدعوى الثانيةَ ويقولُ «سليم». **أعلنّا ذلك ولم نُخفِه** — والنسختانِ مرفقتانِ هنا تُشغَّلانِ جنبًا إلى جنب.

## 3 · طريقُ الاستدلالِ خطوةً خطوة — بلا شبكةٍ بعدَ التنزيل

**تحتاج:** Python 3 و`ssh-keygen` (في macOS وLinux أصلًا، وفي Windows مع OpenSSH). لا مكتباتٍ أخرى، ولا وصولَ إلى مستودعِ الكيان.

1. **افتحْ هذا الملفَّ من الرمز** وقارنْ بصمتَه بالمطبوعةِ بجوارِه: `shasum -a 256 اثبات.md`.
2. **نزّلِ المرآةَ كاملةً:** `git clone --depth 1 https://github.com/up2u2b11/tawthiq-ithbat.git && cd tawthiq-ithbat` — وسجّلْ قيدَ القراءة: `git log -1 --format=%H`.
3. **تأكّدْ أنّ كلَّ شيءٍ هو هو:** في جذرِ المرآة `shasum -a 256 -c MANIFEST.sha256` (كلُّ الملفّاتِ ومنها الحزمة)، ثمّ في هذا المجلّد `shasum -a 256 -c MANIFEST.sha256`.
4. **شغّلِ المتحقّقَ على الحزمةِ المقيسةِ وقارنْ بالمسجَّل حرفًا:**
   ```
   cd تجربة-عبث-02_16-نوفمبر-2026
   python3 -B ../حزمة-2195/tahaqquq_mustaqill.py ../حزمة-2195 | diff - دليل/out_base__v_main.txt && echo مطابق
   ```
   الفرقُ يجبُ أن يكونَ صفرًا (إن كان على جهازِك برنامجُ `ots` فسيزيدُ سطرُ فحصِ أختامِ الزمنِ وحدَه).
5. **اقرأِ النواتجَ الخامَ قبلَ أن تصدّقَ الجدول:** `diff دليل/out_base__v_main.txt دليل/out_a1_seal__v_main.txt` يُظهِرُ سطرَين لا غير: عدّادُ الكسورِ من 5 إلى 6، وسطرُ «انقطاعُ ربطِ prev عندَ الفهرس 1001». ومثلُه مع `a2_forge` بالنسختَين: «✅ سليم» في القديمةِ، و«هاشُ رأسِ ختمٍ موقَّعٍ يخالفُ الدفتر» في الحديثة.
6. **أعِدِ الهجماتِ بنفسِك** على نسخةٍ من الحزمة (الأصلُ لا يُمَسّ):
   ```
   cp -R ../حزمة-2195 /tmp/base && python3 -B دليل/hujum.py /tmp/base
   python3 -B دليل/v_main.py  /tmp/a1_seal   | diff - دليل/out_a1_seal__v_main.txt
   python3 -B دليل/v_qadim.py /tmp/a2_forge  | diff - دليل/out_a2_forge__v_qadim.txt
   python3 -B دليل/v_main.py  /tmp/a2_forge  | diff - دليل/out_a2_forge__v_main.txt
   ```
7. **اخترْ أنتَ الحلقةَ:** `python3 -B دليل/abath_muhakkim.py ../حزمة-2195 1001` (أيُّ رقمِ سطرٍ من 1 إلى 2195؛ الأداةُ تنسخُ الحزمةَ بجوارَها وتقلبُ بايتًا واحدةً وتطبعُ الجديدَ بالأحمر).

## 4 · ما يُنشَرُ هنا وما لا يُنشَر — حدُّ السرّيّةِ مكتوبٌ لا مضمَر

(2) `git clone --depth 1 https://github.com/up2u2b11/tawthiq-ithbat.git`. (3) `shasum -a 256 -c MANIFEST.sha256` at the root and in this folder.
